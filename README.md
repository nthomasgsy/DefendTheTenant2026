# DefendTheTenant2026
Files for Defend The Tenant Challenge

## Approach Taken
I started by running a PowerShell script [Link](Export-M365SecurityInventory.ps1) to gather an Inventory of the Current State, as recommended by the [Link](https://learn.microsoft.com/en-gb/training/modules/harden-microsoft-365-secure-score/2-prepare-safe-administrative-environment "Microsoft Learn Module").

This then produced a zip with various files documenting the existing set up of the tenant.
